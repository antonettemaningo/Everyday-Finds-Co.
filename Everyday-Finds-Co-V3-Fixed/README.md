# Everyday Finds Co.
A GitHub Pages-ready static website for Everyday Finds Co.

## Structure
- `index.html` — homepage
- `style.css` — design system
- `script.js` — small mobile-menu interaction
- `assets/` — local SVG visuals (no external image dependency)
- `guides/` — guide pages
- `about.html`, `privacy.html`, `disclosure.html`

## GitHub Pages
Publish from the `main` branch and the root (`/(root)`) of the repository.
