# Everyday Finds Co.

GitHub Pages-ready website for Everyday Finds Co.

## Upload structure
Keep **all files and folders exactly as they appear** in this package. `index.html` must be in the repository root.

- `index.html`
- `style.css`
- `script.js`
- `about.html`
- `privacy.html`
- `disclosure.html`
- guide HTML files
- `assets/` with the image and SVG illustrations

The site uses relative paths, so it works on a GitHub Pages project URL such as `/Everyday-Finds-Co./`.
